CREDORA · ON-CHAIN TRANSPARENCY

Every position,
as it happened.

Not a dashboard of our own numbers — a log of protocol events, read back from the chain. Deposits, borrows, repayments, withdrawals and liquidations, newest first, each one linked to a transaction you can open in the explorer and verify independently.

Activity data source not connected

This page is a reader, not a source of transaction data. Activity will appear here after the Credora indexer or a compatible on-chain event source has been configured. Until then, no fabricated transaction records are displayed.

Why this page exists

A protocol should not ask users to trust numbers it prints about itself without a way to verify them. This page is intended to make activity independently auditable: individual events, transaction hashes, and links to the relevant blockchain explorer.

The blockchain explorer remains the independent source of truth. If an activity record shown here disagrees with the corresponding on-chain transaction, the transaction on the explorer takes precedence and the indexing issue must be investigated.

Verifiable by design

Credora activity should be traceable to public blockchain records wherever the underlying protocol and network expose those events.
