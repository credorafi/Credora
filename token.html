IMPORTANT LIMITS

What a token should not control

The final scope of any Credora token must be documented clearly. No control rights should be assumed from this draft page.

  • Deposits and user assets Any authority over user assets must be explicitly documented. This page does not establish such authority.
  • Protocol risk parameters Any governance rights and restrictions must be confirmed in the official protocol documentation.
  • Liquidations and withdrawals Rules depend on the deployed protocol and its contracts, not on assumptions made by this frontend.
  • Returns and token price No token utility or participation feature guarantees profits, rewards or appreciation.
